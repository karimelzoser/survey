# Global UAS / Counter-UAS Engineering Atlas — November 2026

This versioned release contains the latest combined UAS and Counter-UAS research presentation, with country and type navigation, bilingual interface, comparison tables, flags, images, video references, and engineering dossiers.

- Online: index.html (view using GitHub Pages).
- Download: download.html (click the Download Offline HTML button to save one self-contained file).

The 13.5 MB source HTML is stored in 21 smaller JavaScript text segments to accommodate upload limits. The browser reconstructs it at runtime; the Download page exports a single-file offline copy. The original repository root presentation remains unchanged.

The inventory is curated rather than exhaustive. Remote media and videos depend on their publishers; independent verification of all manufacturer technical claims has not been established.
